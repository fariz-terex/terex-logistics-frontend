Kebijakan Privasi — LMS Terex

PT. Terex · Berlaku sejak 30 September 2026

LMS Terex (Logistics Management System) adalah aplikasi internal PT. Terex untuk mengelola material, pengiriman, pengembalian, rekonsiliasi, dan stok gudang. Aplikasi ini hanya digunakan oleh karyawan dan mitra kerja PT. Terex yang diberi akun.

Data yang dikumpulkan

  • Data akun pengguna: nama, username, peran (role), dan divisi.
  • Data operasional logistik: material, Serial Number, jumlah, lokasi site/homebase, nomor dokumen (BKB, BMB, Surat Jalan, resi), dan riwayat transaksi.
  • Foto yang diunggah pengguna sebagai bukti kerja, misalnya foto label Serial Number, foto barang, dan foto dokumen.

Penggunaan data

Data hanya digunakan untuk menjalankan proses logistik PT. Terex: mencatat penerimaan dan pengiriman barang, verifikasi fisik material, pembuatan dokumen resmi, dan audit internal. Data tidak dijual dan tidak dibagikan kepada pihak ketiga untuk tujuan lain.

Google Drive

Aplikasi ini dapat terhubung ke akun Google Drive milik PT. Terex (logistik.terex@gmail.com) untuk mengarsipkan foto asli (tidak dikompres) yang diunggah di aplikasi. Aplikasi hanya meminta izin drive.file, sehingga aplikasi hanya dapat mengakses file dan folder yang dibuatnya sendiri dan tidak dapat membaca, mengubah, atau menghapus file lain di Google Drive tersebut. Token akses Google disimpan di server aplikasi dan tidak pernah dikirim ke browser pengguna. Penggunaan data dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Penyimpanan dan keamanan

Data disimpan di server dan penyimpanan objek (object storage) yang digunakan PT. Terex. Akses ke aplikasi memerlukan login, dan setiap pengguna hanya dapat melihat data divisi yang ditugaskan kepadanya.

Penghapusan data

Permintaan koreksi atau penghapusan data dapat diajukan ke PT. Terex melalui kontak di bawah. Koneksi Google Drive dapat diputus kapan saja oleh administrator dari menu Settings di aplikasi, atau dari halaman keamanan akun Google (myaccount.google.com/permissions).
